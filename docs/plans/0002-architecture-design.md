# 0002：微内核架构定稿

- 状态：待领取
- 前置：ADR-0001 已接受，初始化模板完成

## 目标

在不写架构实现代码的前提下，完成微内核详细设计，替换 `docs/architecture.md` 的草案内容，并形成可独立实施的后续任务票。

## 设计任务

- [ ] 契约形状：定义 Core 的职责边界、主要抽象、公开 API 与依赖方向。
- [ ] 加载模型：比较插件发现、加载、激活、隔离及失败处理方案。
- [ ] 消息机制：明确宿主/插件与插件/插件通信、订阅、生命周期和错误语义。
- [ ] UI 组合：明确导航、视图注入、资源、标签页和卸载行为。
- [ ] 版本策略：定义契约兼容规则、插件目标版本、升级与依赖处理。
- [ ] 说明上述设计如何支撑 P0/P1/P2，记录备选方案及取舍。

## 交付与验收

- [ ] 将定稿设计写入 `docs/architecture.md`，移除草案标识和已解决待决项。
- [ ] 为新增或改变的架构决策补充 ADR，并链接相关设计章节。
- [ ] 将设计拆分为边界清晰、可独立验收的实现票。
- [ ] 运行 `dotnet run scripts/check.cs`，确认文档调整未破坏工程检查。
- [ ] 本票不包含插件加载器、消息总线、DI 容器接入或 UI 组合实现。
