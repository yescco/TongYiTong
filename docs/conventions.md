# 编码约定

## C# 与 XAML

- 命名空间与项目名一致；类、方法、属性、事件使用 `PascalCase`。
- 参数和局部变量使用 `camelCase`；私有字段使用 `_camelCase`。
- 异步方法以 `Async` 结尾；接口以 `I` 开头。
- XAML 元素、属性和事件处理器使用 `PascalCase`，资源键使用有语义的 `PascalCase`。
- 文件换行、缩进和字符集遵循根目录 `.editorconfig`，提交前运行格式检查。

## MVVM

- View 只负责呈现和交互转发，业务逻辑放 ViewModel 或应用服务。
- ViewModel 不直接依赖窗口、对话框等具体 View 类型。
- 使用 `CommunityToolkit.Mvvm` 实现通知与命令；架构未定的部分不预建通用框架。
- 数据通过明确契约流动，避免在视图间共享可变静态状态。

## 文档注释

- 每个类型、成员等声明处写一行该语言惯用的文档注释，回答“是什么”。
- 声明之外默认不写注释；代码应优先自解释。
- 注释使用短句，不堆积设计背景；背景写入 `docs/` 或 ADR。

## 自动化标识

- 关键窗口、按钮、输入框、列表、标签页等控件必须显式设置 `AutomationProperties.AutomationId`。
- 标识使用稳定的 `PascalCase` 名称，不带运行时序号，不随显示文案变化。
- E2E 通过 AutomationId 定位关键控件，不依赖坐标、视觉文本或任意等待。
- 新增关键交互时同步补充标识和相应测试。
