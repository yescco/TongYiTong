# 产品路线图

同易通面向串口调试，界面使用中文。阶段按可交付价值推进，不提前实现后续架构。

## P0：终端与 CRC 工具

- 单串口终端收发，支持 ASCII/HEX 显示与发送。
- 接收内容带时间戳，发送历史可回看。
- 支持定时发送与收发日志。
- 提供 CRC 校验计算工具。

## P1：多会话与真实 UI 冒烟

- 多串口、多标签并行工作。
- 使用 FlaUI UIA3 编写真实 E2E 冒烟用例，覆盖启动和关键交互。
- 将现有 UI 占位测试替换为真实用例；不在后台会话中假定桌面交互可用。

## P2：协议解析插件框架

- 基于微内核方向定稿协议解析插件框架。
- 支持通过契约扩展协议解析能力。
- 具体契约、加载、消息与 UI 组合机制由 [0002 任务票](plans/0002-architecture-design.md) 定稿。
